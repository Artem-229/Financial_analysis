### Суть приложения - анализа трат пользователей и предоставление советов по финансовой грамотности

Пользователь ведёт свои траты, каждая привязана к фиксированной категории.  
Go считает агрегаты (суммы/категории/аномалии), локальная LLM раз в период превращает  
готовое саммари в разбор -> советы по финансовой грамотности и присылает в Telegram и в личный кабинет.
